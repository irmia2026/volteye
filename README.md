# VoltEye

微信群消息采集与工单结构化工具（Windows）。自动读取本机微信 4.x 的加密数据库，把群里收到的南方电网工单短信解析成结构化记录，一键导出生产级 Excel 报表。

> ⚠️ 仅供采集本人微信账号中合法接收的消息。请确保用途合规。

## 功能

- **自动探测**：免配置找到微信数据目录（4.x config ini → 注册表 → 文档/用户目录/盘符根目录），支持自定义存储位置
- **自动解密**：从微信进程内存提取数据库密钥（支持 `-key` 手动指定），SQLCipher 解密 + WAL 增量回放，每 3 秒轮询新消息
- **结构化解析**：可配置的格式引擎（签名正则 + 括号对 + 字段别名表），内置 5 种南网工单格式（csg-a~e），覆盖 `【】`/`[]`/`()` 三种括号、KF 报障单、无前缀转发；签名命中但解析失败会记入异常，不会静默丢单
- **关键词打标**：独立的规则引擎（关键词/正则），用于任意自定义消息标记
- **生产级导出**：样式化 Excel（标题/冻结/筛选/斑马纹/紧急程度条件色/自动行高），按业务类型分 sheet，支持追加到旧文件（单号去重、保留人工填写）
- **托盘常驻**：`-tray` 模式关窗后台运行；支持开机自启、保留期/容量自动清理（清理前自动归档）

## 快速开始

```
volteye.exe
```

微信 4.x 保持登录即可，数据目录和密钥全部自动获取。首次启动后：

1. **群管理**面板（按 `2`）：空格勾选要采集的群，`b` 开启历史回填，`/` 搜索群
2. **工单**面板（按 `3`）：查看解析出的工单，`x` 导出新表，`a` 追加到已有导出文件
3. **格式**面板（按 `5`）：查看/新增/编辑消息格式定义
4. **规则**面板（按 `6`）：自定义关键词打标，`R` 重扫历史消息

### 命令行参数

| 参数 | 说明 |
|---|---|
| `-dbstorage <path>` | 手动指定 `db_storage` 目录（自动探测失败时） |
| `-key <64位hex>` | 手动指定数据库密钥（跳过内存扫描） |
| `-data <dir>` | 数据目录（默认 exe 所在目录的 `data\`） |
| `-interval 3s` | 轮询间隔 |
| `-tray` | 系统托盘模式，关窗不退出 |

密钥提取需要管理员权限（右键 → 以管理员身份运行）。

### 导出

工单面板按 `x` 生成 `VoltEye_工单_<时间戳>.xlsx`；按 `a` 追加到指定旧文件（已存在的工作单号自动跳过，人工填写的"是否完成"等列不受影响）。导出列与供电所工单汇总习惯一致：紧急程度/业务类型/故障子类/具体故障/工作单号/派工时间/地址/联系人/联系方式/联系电话/诉求内容/用户编号/用户名称/是否完成。

## 新消息格式接入

括号键值对类的新格式**不用改代码**：格式面板按 `n`，填写：

- 名称：如 `csg-f-催办单`
- 签名正则：如 `催办单号为：【`（建议锚定带括号的字段名，避免和其他格式互相命中）
- 括号对：如 `【` `】`
- 字段映射：每行一条 `源字段=规范字段`，规范字段集：`order_no dispatch_time address description contact_name contact_way contact_phone category user_no user_name`
- 分类链标记：可选，如 `业务类型为`（用于 `[一般]-业务类型为：-[a]--[b]` 结构）

非括号 KV 的格式（纯文本模板等）需要实现 `capture.Extractor` 接口注册新 kind，见 `docs/ARCHITECTURE.md`。

## 构建与开发

```
go build -o dist\volteye.exe ./cmd/volteye   # 主程序
go test ./...                                 # 测试
```

要求 Go 1.25+，仅支持 Windows（密钥扫描/托盘/探测为 Windows 实现）。无 CGO 依赖（SQLite 用 modernc.org/sqlite）。

辅助入口：`cmd/volteye-m0`（解密验证）、`cmd/volteye-m1`（采集验证 CLI）——开发调试用，勿分发。

## 数据布局

```
<exe目录>\data\
  volteye.db        本地库：消息流水 / 工单 / 格式定义 / 规则 / 设置
  work\dec\         解密后的微信库镜像（采集缓存，约等于微信库本身体积）
  work\enc\         解密中间文件（临时，用完即删）
  exports\          导出的 Excel
  archive\          清理策略触发的自动归档
```
